Instrucciones

1. Seleccionar Estado

Haga clic en el boton del estado correspondiente para comenzar el registro de equipamiento.

2. Registrar Datos del Usuario

Complete el formulario con nombre y correo electronico.

3. Seleccionar Unidad Medica

Elija la unidad medica especifica que desea registrar en el selector desplegable.

4. Configurar Consultorios

Ingrese el numero de consultorios que tiene la unidad y presione "Aplicar".

5. Preguntas Individuales

Responda las preguntas que no dependen de consultorios:

  • Internet: Seleccione SI o NO
  • Consultorios Generales Habilitados: Ingrese el número (puede ser 0)

6. Llenar Cuestionario

Haga clic en cualquier celda para editarla, ingrese el valor y presione ACEPTAR.

VERDE: Valor > 0 registrado

AZUL: Valor 0 registrado (válido)

ROJO: Campo pendiente - Haga clic para llenar

FILA VERDE: Unidad ya guardada en la base de datos

7. Guardar Unidad

Una vez que haya llenado los campos, presione el boton "Guardar unidad".

8. Ver Detalles

Haga clic en "Ver detalles" para mostrar informacion de la unidad.

Consejos

  • Use solo numeros enteros para las cantidades
  • El 0 es un valor válido y se puede guardar
  • Debe presionar ACEPTAR en cada celda antes de guardar
  • El progreso local se guarda automaticamente
  • Pase el mouse sobre cualquier celda para ver que pregunta esta respondiendo
  • Las columnas de consultorios se generan dinamicamente

Soporte

Si tiene problemas, contacte al area de sistemas de IMSS Bienestar.
